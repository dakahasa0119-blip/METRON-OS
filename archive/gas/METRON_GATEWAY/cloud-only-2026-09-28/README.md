# Historical Gateway cloud-only modules (snapshot: 2026-09-28)

These six files are the previously unpublished **original Apps Script module
sources** from the verified local snapshot of the cloud project recorded as
`スマホgateway`, preserved on 2026-09-28. They are NOT revised Node.js
references and are NOT a live deployment.

The files were checked for literal URLs, email addresses, and common embedded
credential formats before being placed here. After checkout on Windows, all
six were checked byte-for-byte against the original SHA-256 inputs **after
normalizing Git's automatic CRLF checkout conversion to original LF**.
All six compared equal; no code functionality was modified.

This folder contains ONLY the six files missing from the earlier historical
Git snapshot. It is *not* the complete 15-file September cloud project; five
other cloud files differed from their older Git counterparts and require
separate, version-specific preservation review. The archived .clasp metadata,
private spreadsheets, execution logs and live deployment IDs are omitted.
